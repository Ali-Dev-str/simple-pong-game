# Simple Pong Game

A simple 2D Pong game built using Python and the Pygame library. This project focuses on basic game mechanics, rendering shapes (rectangles and circles), and handling keyboard events for player movement.

## Features
* Two players control (Player 1 uses Arrow keys, Player 2 uses Numpad 8 and 2).
* Paddle boundary locks to prevent moving off-screen.
* Smooth 60 FPS game loop execution.

## How to Run
1. Install Pygame:
   ```bash
   pip install pygame
   ```
2. Run the code to start moving the paddles!
